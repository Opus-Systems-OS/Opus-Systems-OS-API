# com.opussystems.api

The Opus Systems OS API client as a Unity package. Reference it by git URL:

```json
"com.opussystems.api": "https://github.com/Opus-Systems-OS/Opus-Systems-OS-API.git?path=/sdk/upm/com.opussystems.api"
```

Sources are a copy of `sdk/csharp/OpusSystems.Api`, kept current by
`sdk/unity/sync-sdk.sh` (CI checks). See `sdk/csharp/README.md` for usage.
